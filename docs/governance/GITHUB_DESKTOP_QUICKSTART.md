# GitHub Desktop 小白指南(一页)

> 面向非程序员。无需学习 Git 命令行。

## 第一次使用

1. 安装 **GitHub Desktop**(github.com/apps/desktop);
2. 打开 GitHub Desktop → 登录 GitHub 账号;
3. 点击 **Clone repository** → 选择 `Yokoo3431/Maple-AI-Companion-Agent`;
4. 选择本地文件夹 → Clone;
5. 打开 Codex 指向该文件夹。

## 每次从另一台电脑回来

1. 打开 GitHub Desktop;
2. 选择 Maple repository;
3. 点击 **Fetch origin**(把 GitHub 最新内容拿到当前电脑);
4. 如显示 **Pull origin**,点击 Pull(获取别人的/另一台电脑的修改);
5. 确认左侧 Changes 为空;
6. 打开 Codex 开始工作。

## 开发结束

1. Codex 完成测试后;
2. GitHub Desktop 左侧 **Changes** 查看修改;
3. 填写 Summary,点击 **Commit to main**(保存到本机历史);
4. 点击 **Push origin**(把本机新提交上传 GitHub);
5. 打开 GitHub 仓库 Actions 页面,确认测试通过。

## 按钮含义

```text
Fetch origin  = 检查 GitHub 是否有更新(只读)
Pull origin  = 把 GitHub 更新合并到本机
Commit       = 在本机记录一次修改
Push origin  = 把本机提交上传 GitHub
```
