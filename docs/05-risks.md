| --- | --- | --- | --- | --- | --- |
| R1 | 游戏运营方禁止第三方自动化,存在账号处罚/封禁风险 | 合规/账号 | 高 | 中 | 仅用于个人怀旧服/学习环境;README 声明责任;提供保守参数与人工确认 |

| R4 | 不同怀旧服版本 UI/地图数据差异 | 知识库 | 中 | 中 | 知识包版本绑定 + 启动检测提示 + 更新报告 |
| R5 | DeepSeek API 延迟/超时/限流 | 规划层 | 中 | 中 | 超时/重试/熔断;L1 不依赖 AI;失败降级为本地规则 |
| R6 | 窗口丢失/最小化/焦点变化导致误操作 | 安全 | 高 | 中 | 窗口绑定校验 + 自动暂停 + 执行门控 |
| R7 | 状态机竞态 / 事件丢失 / 循环卡死 | 核心 | 高 | 低 | 单写者事件队列 + 心跳看门狗 + 超时恢复 |

| R12 | 日志/会话数据无限增长 | 运维 | 低 | 中 | 轮转 + 保留策略 + 会话按需清理 |

## 风险处置约定

- R1、R8 属于高风险项,Phase 0 通过"禁止真实输入 + 三重门控"从架构上规避,后续阶段保持;
- R2、R3 依赖 Phase 1 视觉实现的实测数据,OCR 引擎选型(Windows OCR / PaddleOCR / Tesseract)与窗口检测 API 待环境实测确认,记录在 [01-system-design.md](01-system-design.md) 第 9 节;
- 其余风险在对应里程碑评审时复核更新。
